# 设备联调工具 · 系统配置

原“快捷使用”模块已更名为“系统配置”，截图、贴图和离线文字识别仍在这个页面。

| 选项 | 行为 |
| --- | --- |
| 开机自启动（后台运行） | 登录当前 Windows 账户后自动运行，只显示托盘图标，不弹出主窗口 |
| 启动时默认启用截图功能 | 下次手动启动或开机自启动时，自动注册 F1 截图 / F3 贴图快捷键 |
| 当前启用截图快捷键 | 立即开启或关闭本次运行的截图功能，不改变下次启动偏好 |
| 隐藏到托盘 | 隐藏主窗口，保留后台通信和已开启的截图功能 |

前两个选项首次默认关闭，修改立即保存。开机自启动不自动开启截图，需要同时勾选“启动时默认启用截图功能”。热键冲突时保持截图关闭并显示错误，下次启动偏好保留。

双击托盘图标打开主界面；右键菜单可打开系统配置、切换当前截图开关或退出。再次启动设备联调工具会唤回当前 Windows 会话中已有的新版实例。点击主窗口叉号仍会退出，并释放连接、快捷键和浮窗。

自启动使用当前用户的 Windows Run 启动项，不需要管理员权限。程序必须保留在固定的完整发布目录中。升级时先退出旧版，再运行新版；若启动项路径不同，点击“更新为当前版本”。移动目录后也需更新。若已登记却未运行，请检查 Windows 设置中的“启动应用”是否允许设备联调工具（程序文件名仍为 `LinkLab.exe`）。

Windows 可能延迟启动应用；这里的“开机”指用户登录后运行，不是在登录前运行的系统服务。[Microsoft Run 启动项说明](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)

截图偏好保存在 `%LOCALAPPDATA%\LinkLab\settings.json`；实际自启动状态从 Windows 读取。仅加载配置不会重新启用已被移除的启动项。

## 截图编辑

开启截图后按 **F1**，拖动框选区域。选好后可以继续编辑：

- 使用移动工具拖动选区；拖动边框或八个控制点调整选区大小。
- 滚轮或工具栏的缩放按钮放大、缩小画布；空格加拖动或鼠标中键拖动画布。预览缩放不会改变导出图片的原始分辨率。
- 使用文字工具在选区内添加说明，使用矩形或正方形工具画框。工具栏颜色可以切换标注颜色；撤销可逐步回退标注。
- 点击复制、保存或贴图，输出包含标注的图片。点击文字识别时，识别原始选区内容。
- **Enter** 完成截图，**Esc** 取消。

按 **F3** 贴图后，可拖动移动浮窗、滚轮缩放，使用比例重置恢复 100%；**Ctrl + 滚轮**调整透明度。可从贴图菜单复制图片或识别文字。
