# 设备联调工具 · 网口配置软件

此模块参考卓岚 VirCom 的设备管理流程，按厂家公开的 [UDP 管理端口协议](https://www.zlmcu.com/download/UDP_port_protocol.pdf)独立实现，不依赖参考程序或厂商 DLL。管理通信使用 UDP 1092，和“TCP / UDP”模块的数据收发连接独立。

## 使用步骤

1. 打开 **网口配置软件**，选择连接设备的本机 IPv4 网卡。
2. 点击 **搜索局域网设备**，或填写设备 IP 后点击 **按 IP 查询**。页面打开时不会自动搜索。未收到应答时，检查网卡、设备供电、连接和 UDP 1092 是否可达。
3. 选择设备后查看设备 ID、原 IP 和当前参数；需要时先 **重读所选设备**。
4. 编辑设备名称、IP / 子网掩码 / 网关、DHCP、工作模式、本地与目标端口、目标 IP 或域名，以及波特率、数据位、校验、停止位和流控。可选择透明传输、Modbus TCP ↔ RTU 或 RealCom 转化协议，选项仍受设备声明的功能限制。
5. 点击 **检查修改**，核对目标设备及参数，再点击 **确认并写入设备**。写入会使设备重启；设备设置了配置密码时，需填写设备密码。
6. 程序重新读取相同设备 ID 的参数，比对通过后才显示成功。若提示“已发送但未确认”，请先重新搜索和核对设备，避免重复写入。

TCP Client 模式的 **本地端口可以为 0**，表示由设备随机选择空闲端口；固定本地端口可填 1–65535。TCP Server、UDP 和 UDP Multicast 的本地端口以及所有模式的目标端口仍须填写 1–65535。检查修改和写入会保留 TCP Client 的 0，预览中显示“0（随机）”。参见厂家 [TCP 客户端与服务器说明](https://www.zlmcu.com/FAQ/TCP%20client%20and%20TCP%20server.pdf)。

单独重启时，选中设备并点击 **重启所选设备**，核对设备 ID / IP 后确认。程序会重新读取设备当前完整参数，按厂家协议发送一次保留参数的重启指令，不会提交编辑区尚未写入的修改；启用配置密码的设备仍需输入密码。随后轮询同一设备的参数；回读只能确认设备应答与参数一致，协议没有独立的重启完成应答。超时显示结果未确认，不会自动重发。

设备可能使用不同网段的出厂 IP。发现设备不代表当前电脑能路由到该 IP；若定向读取或配置超时，请检查本机与设备之间的网络可达性。

## 模板与兼容范围

参数可导出为 JSON 模板。模板只包含编辑区参数，不包含设备 ID、原始应答、配置密码或 Wi-Fi 密钥；载入模板不会自动写入设备。每次写入仍以当前选中设备的新读取结果为基础，保留未编辑的认证、功能标志和扩展区域。

目前写入支持厂家文档中的 167 字节参数格式；其他可识别长度只读展示。未实现固件升级、P2P、设备密码修改或其他厂家的私有管理协议。普通网卡的本机 IP 不会被这个模块修改。

协议编解码、设备身份检查与 UDP 交互使用本机模拟设备验证；不同实物型号与固件仍需实机确认。
