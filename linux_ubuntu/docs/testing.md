# 设备联调工具 · Python Qt 兼容性与验证范围

设备联调工具的 Python Qt 版已在 Windows x64、Python 3.12、PySide6 6.8.3 环境验证。Ubuntu 22.04 / 24.04 为目标平台，桌面与实机验证尚待完成。

| 功能 | 已验证 | 仍需对应环境确认 |
| --- | --- | --- |
| 串口 / 网络 | TCP 多客户端、UDP、串口回环与本机 RTU 串口桥 | USB/RS485 驱动、电气时序和真实串口设备 |
| Modbus / PLC | Modbus 八种功能码；S7、MC3E、FINS/TCP 握手、读写和内存模拟 | 具体 PLC 型号、固件及设备配置 |
| MQTT | TCP 3.1.1/5.0、QoS0/1/2、发布订阅、Retain、重连 | TLS / WS / WSS 实际服务端；当前仅验证相关配置与证书/主机名检查设置 |
| 网口配置 | ZLAN 协议本机 UDP 模拟设备的发现、读取、写后回读、保留参数重启和超时不重发 | ZLAN 实物广播、重启及 Linux 网卡定向广播 |
| 截图 / OCR | Windows 截图编辑、DPI 映射、贴图、原图 OCR、热键冲突与退出清理 | Ubuntu X11 截图、热键、Tesseract 语言包及桌面托盘 |

Wayland 下不提供全局 F1/F3；屏幕读取是否可用取决于系统权限。可使用系统截图工具，再从剪贴板贴图或打开图片进行 OCR。自启动和默认截图首次均关闭。

截图展示中的网口设备为演示数据，不代表实物连接。模拟器提供协议和内存访问，不执行 PLC 程序。Windows WPF 版的测试结果不代表 Python 版已在相同真实设备上验证；两个版本的配置与快照格式独立。

测试命令见 [使用说明](../README.md#测试与源码打包)，结果写入本地忽略目录 `artifacts/`。

多屏截图回归覆盖 150% / 125% 混合缩放、负坐标、跨屏接缝、原生像素裁剪、缩放与标注同步、跨屏文字重编辑和空格平移释放。Windows 原生 Qt 后端另验证两块屏幕各自的窗口几何、DPI、右下角绘制和完整导出；使用合成图与隐藏测试窗口，不保存真实桌面内容。截图过程中显示器接入、移除或几何变化会关闭所有选区窗口。
